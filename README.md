# Park Checklist PWA

Application web installable sur Android.

## Hébergement gratuit avec GitHub Pages
1. Crée un compte GitHub si besoin.
2. Crée un nouveau dépôt, par exemple `park-checklist`.
3. Envoie tous les fichiers de ce dossier à la racine du dépôt.
4. Dans GitHub : Settings > Pages.
5. Dans "Build and deployment", choisis "Deploy from a branch".
6. Sélectionne la branche `main` et le dossier `/ (root)`, puis Save.
7. GitHub affichera l'adresse de ton site.
8. Ouvre cette adresse dans Chrome sur Android.
9. Menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil.

La progression est stockée sur l'appareil avec localStorage.
Utilise Exporter / Importer pour faire une sauvegarde ou me renvoyer ta progression.
